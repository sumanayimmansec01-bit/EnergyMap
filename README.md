# แผนที่พลังงาน (Energy Map)

เว็บแอพมือถือ (PWA) บันทึกว่ากิจกรรมไหน **เติมพลัง** หรือ **ดูดพลัง** แล้วสรุปเป็น **รายวัน / รายสัปดาห์ / รายเดือน**

## ใช้งาน
- เลือกธีมได้ที่แท็บ **จัดการ → ธีมสี**: มาริโอ (ค่าเริ่มต้น), คลาสสิก, อาร์เคด
- แตะกิจกรรมสำเร็จรูป 16 อย่าง (หรือเพิ่มเอง) เลือกระดับ ▼▼ ▼ ▲ ▲▲ ระยะเวลา และเวลา (ย้อนหลังได้)
- ตั้งคะแนนเองครั้งละ −5 ถึง +5 (คะแนนที่ใส่คือคะแนนจริง ระยะเวลาเก็บไว้ดูเฉย ๆ)
- หน้าสรุป: กราฟพลังสุทธิ, ตัวชาร์จ/ตัวดูดพลังอันดับต้น, คำแนะนำอัตโนมัติ (ช่วงเวลาที่พลังดี/ตก, วันที่พลังลด)
- ข้อมูลเก็บในเครื่องเท่านั้น สำรอง/นำเข้าเป็น JSON ได้

## ติดตั้งลงมือถือ
เปิดผ่าน GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) แล้ว
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ไฟล์ทั้งหมดเป็น HTML/JS ล้วน ไม่ต้อง build ใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## ทดสอบ (E2E)
```bash
npm install
npm run test:e2e
```

## 🎮 เกมพักสมอง (2–5 นาที)
แท็บ **เกม** มี 4 เกม ไม่มีเวลาไล่หลัง แพ้ไม่มี เริ่มใหม่ได้เสมอ: 🌷 จัดกระถางดอกไม้ · 🍄 พลิกการ์ดจับคู่ · 🌱 รวมเมล็ดเป็นต้นไม้ · 🧩 สไลด์ภาพเห็ด
- เล่นจบแล้วกด **บันทึกเป็นกิจกรรมเติมพลัง** ได้ (+1 ปรับได้ทีหลังเหมือนกิจกรรมอื่น) ไม่บันทึกให้เอง
- ทางลัด: ลิงก์ตรง `?game=sort|memory|merge|slide` และเมนูกดค้างที่ไอคอนแอพ (Android)
- สถิติเกมเก็บในเครื่อง; ใส่ `?seed=123` เพื่อให้สับไพ่/สุ่มซ้ำได้ (ใช้ในเทสต์)
- โค้ดเกมอยู่ใน `games.js`
