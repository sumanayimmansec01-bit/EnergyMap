# แผนที่พลังงาน (Energy Map)

เว็บแอพมือถือ (PWA) บันทึกว่ากิจกรรมไหน **เติมพลัง** หรือ **ดูดพลัง** แล้วสรุปเป็น **รายวัน / รายสัปดาห์ / รายเดือน**

## ใช้งาน
- เลือกธีมได้ที่แท็บ **จัดการ → ธีมสี**: มาริโอ (ค่าเริ่มต้น), คลาสสิก, อาร์เคด
- แตะกิจกรรมสำเร็จรูป 16 อย่าง (หรือเพิ่มเอง) เลือกระดับ ▼▼ ▼ ▲ ▲▲ ระยะเวลา และเวลา (ย้อนหลังได้)
- ตั้งคะแนนเองครั้งละ −5 ถึง +5 (คะแนนที่ใส่คือคะแนนจริง ระยะเวลาเก็บไว้ดูเฉย ๆ)
- หน้าสรุป: กราฟพลังสุทธิ, ตัวชาร์จ/ตัวดูดพลังอันดับต้น, คำแนะนำอัตโนมัติ (ช่วงเวลาที่พลังดี/ตก, วันที่พลังลด)
- ข้อมูลเก็บในเครื่องเท่านั้น สำรอง/นำเข้าเป็น JSON ได้

## ของน่ารัก ๆ
- **เห็ดน้อย (มาสคอต)** อยู่ในการ์ดวันนี้ หน้าตาเปลี่ยนตามพลังสุทธิของวัน (รอฟัง / ดีใจ / ยิ้ม / สบายใจ / เหนื่อย / ง่วง) และเชียร์ 4 วินาทีหลังบันทึกกิจกรรมหรือเล่นเกมจบ
- **สวนสัปดาห์นี้** (แท็บสรุป รายวัน/รายสัปดาห์) แต่ละวันคือแปลงหนึ่ง: เติมพลังมากขึ้น ต้นอ่อนโตเป็นตุ้มดอกและดอกไม้ (สูงสุด 3 ดอก) วันที่เสียพลังมากมีเมฆฝน
- **การ์ดสรุปสัปดาห์** สร้างเป็นรูป PNG แชร์เข้า LINE ได้ด้วยปุ่มแชร์ของมือถือ หรือบันทึกเก็บไว้ ดูตัวอย่างก่อนส่งเสมอ ไม่ส่งอะไรออกไปเอง
- โค้ดอยู่ใน `extras.js`

## ติดตั้งลงมือถือ
เปิดผ่าน GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) แล้ว
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ไฟล์ทั้งหมดเป็น HTML/JS ล้วน ไม่ต้อง build ใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## ทดสอบ (E2E)
```bash
npm install
npm run test:e2e
```

## 🎮 เกมพักสมอง (2–5 นาที)
แท็บ **เกม** มี 10 เกม เริ่มใหม่ได้เสมอ: 🌷 จัดกระถางดอกไม้ · 🍄 พลิกการ์ดจับคู่ · 🌱 รวมเมล็ดเป็นต้นไม้ · 🧩 สไลด์ภาพเห็ด · 🧺 เลื่อนรับลูกบอล (รอบละ 45 วินาที) · 🀄 จับคู่ไพ่มาจง (3 ชั้น 36 ใบ ทุกกระดานจบได้แน่นอน) · 🧱 เทตริส (เริ่มช้า เร็วขึ้นทุก 10 แถว) · 🥚 ยิงไข่ไดโนเสาร์ (ไข่ 5 สี มีสัญลักษณ์กำกับ ยิงให้ครบ 3 ฟองเพื่อให้แตก) · 💎 เรียงเพชร (สลับเพชรข้างกันให้ได้ 3 เม็ดเรียงกัน 25 ตา สลับที่ไม่ได้อะไรไม่เสียตา) · 🟦 จัดบล็อกให้พอดีแถว (วางบล็อกบนกระดาน 8×8 ให้เต็มแถว/คอลัมน์แล้วหาย แตะดูตำแหน่งก่อนวางจริง ไม่มีเวลา)
- เล่นจบแล้วกด **บันทึกเป็นกิจกรรมเติมพลัง** ได้ (+1 ปรับได้ทีหลังเหมือนกิจกรรมอื่น) ไม่บันทึกให้เอง
- ทางลัด: ลิงก์ตรง `?game=sort|memory|merge|slide` และเมนูกดค้างที่ไอคอนแอพ (Android)
- สถิติเกมเก็บในเครื่อง; ใส่ `?seed=123` เพื่อให้สับไพ่/สุ่มซ้ำได้ (ใช้ในเทสต์)
- โค้ดเกมอยู่ใน `games.js`
